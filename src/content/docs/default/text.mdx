Small sizes stay readable, and from `h4` up every heading is fluid: it grows smoothly between a phone and a wide screen, so a page looks designed at every width without breakpoints. Weights, families, line height and letter spacing are on the [Text](/css/text/) page.

## Sizes

| Token | Size | Use it for | Sample |
|---|---|---|---|
| `tiny` | 0.75rem | Legal text, fine print | <span class="font:tiny">Aa</span> |
| `eyebrow` | 0.8125rem | Labels above headings | <span class="font:eyebrow">Aa</span> |
| `small` | 0.875rem | Captions, secondary text | <span class="font:small">Aa</span> |
| `base` | 1rem | Body text | <span class="font:base">Aa</span> |
| `h6` | 1.125rem | Small headings | <span class="font:h6">Aa</span> |
| `h5` | 1.375rem | Card titles | <span class="font:h5">Aa</span> |
| `h4` | 1.625rem to 2rem | Subsection headings | <span class="font:h4">Aa</span> |
| `h3` | 2rem to 2.75rem | Section headings | <span class="font:h3">Aa</span> |
| `h2` | 2.5rem to 3.75rem | Page headings | <span class="font:h2">Aa</span> |
| `h1` | 3rem to 5rem | Page titles | <span class="font:h1">Aa</span> |
| `display` | 3.5rem to 7rem | Hero headlines | <span class="font:display">Aa</span> |

The fluid sizes are CSS `clamp()` values. `h1`, for example, is `clamp(3rem, 2rem + 4vw, 5rem)`.

```html title="A hero headline, tight and bold"
<h1 class="font:display:bold:extra-tight text:grey-4:none">…</h1>
```

<Aside title="Make it yours">
Change any size in `elevate/core/system/design/typography.ts`. Fixed values and `clamp()` both work.
</Aside>
