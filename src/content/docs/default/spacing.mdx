Every spacing value in Elevate is a named step on one ruler. Use the tokens anywhere a property takes a length: `pd` and `mg`, `gap`, `w` and `h`, `max-w`, and offsets like `inset`.

<SpacingLab />

## Three scales, one ruler

The steps are grouped by what they're for, and the letter tells you which group you're in. `d` is for detail inside components, `c` is for room between blocks and sections, and `s` is for widths and page structure. Each scale picks up where the one before it ends.

<SpacingScales view="map" />

### Detail scale

Tokens start with `d` and run from `0.125rem` to `3.5rem`, climbing in even 4px steps from `d1` to `d12`. Use them for padding, gaps and offsets inside buttons, cards, inputs and lists. `px` adds a one-pixel hairline for borders and dividers. The bars below are drawn at their real width.

<SpacingScales view="d" />

### Content scale

Tokens start with `c` and run from `4rem` to `20rem`. Use them for space between sections, column gaps in page layouts, and the size of media like avatars, thumbnails and icon tiles.

<SpacingScales view="c" />

### Space scale

Tokens start with `s` and run from `24rem` to `120rem`. Use them for widths: a readable text column, a dialog, a sidebar, or the maximum width of a page.

<SpacingScales view="s" />

## Using them together

```html title="A pricing card, a section and a page column"
<article class="pd:d6 gap:d4 bd:round-d4">…</article>
<section class="pd-y:c5 gap:c1">…</section>
<main class="max-w:s10 mg-x:auto">…</main>
```

The [Margin and padding](/css/marginpadding/) page covers giving each side its own value.

<Aside title="Make it yours">
These are starting values. Change them, or add your own, in `elevate/core/system/design/spacing.ts`. The [Configuration](/guides/3-configuration/) guide shows how.
</Aside>
