Each family runs from `-4` to `+4` in evenly spaced steps of lightness, and there's also `black`, `white` and `transparent`. White text is readable on every base color except yellow, which is made for dark text. Use any of them anywhere a property takes a color.

## Writing a color

Name the family, then add a step if you want something other than the base: `text:purple`, `bg-color:red-1`, `bd:indigo+2`.

| Step | Tone | Good for |
|---|---|---|
| `-4` | Darkest | High-contrast text, strong emphasis |
| `-3` | Very deep | Text on light backgrounds, bold accents |
| `-2` | Deep | Strong accents, outlines |
| `-1` | Moderately dark | Borders, icons, subtle emphasis |
| *(none)* | Base | Brand elements, primary highlights |
| `+1` | Lighter | Hover states, gentle highlights |
| `+2` | Soft | Secondary backgrounds, quiet UI |
| `+3` | Pastel | Large backgrounds |
| `+4` | Lightest | Near-white surfaces, dividers |

`black` and `white` have no steps. `transparent` works with every color property, for example `bg-color:transparent` or `bd:transparent`.

<Aside title="Make the palette yours">
These are starting values. Override them or add your own families in `elevate/core/system/design/colors.ts`. The [Configuration](/guides/3-configuration/) guide shows how.
</Aside>
