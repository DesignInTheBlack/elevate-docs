One property, `shadow`, handles both box shadows and text shadows. Elevate picks the right CSS property from the token.

## Box shadows

<ShadowGallery view="box" />

`shadow:none` removes a shadow, for example to flatten a card on a state.

```html title="A card that lifts on hover"
<article class="shadow:subtle transition:snappy @hover:[shadow:lifted]">…</article>
```

## Text shadows

<ShadowGallery view="text" />

```html title="A caption that stays readable over a photo"
<figcaption class="text:white shadow:soft-text">…</figcaption>
```

<Aside title="Shadows are design tokens">
Change these, or add your own, in `elevate/core/system/design/effects.ts`.
</Aside>
