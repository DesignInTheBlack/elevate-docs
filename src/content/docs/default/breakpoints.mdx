Each breakpoint is a minimum width. Classes after `/md/` apply from 768px up, so you write the phone layout first and add changes as the screen grows.

| Breakpoint | Min width | Pixels | Typical screen |
|---|---|---|---|
| `2xs` | `20rem` | 320px | Small phones |
| `xs` | `30rem` | 480px | Large phones |
| `sm` | `40rem` | 640px | Phones in landscape |
| `md` | `48rem` | 768px | Tablets in portrait |
| `lg` | `64rem` | 1024px | Tablets in landscape, small laptops |
| `xl` | `80rem` | 1280px | Laptops |
| `2xl` | `96rem` | 1536px | Large laptops and monitors |
| `3xl` | `120rem` | 1920px | Full HD displays |
| `4xl` | `160rem` | 2560px | QHD displays |
| `5xl` | `240rem` | 3840px | 4K displays |

<Aside title="Make it yours">
Change these values in `elevate/core/system/design/breakpoints.ts`. Keep them in ascending order, since Elevate writes media queries in the order they're listed, and keep names to three letters or numbers: the compiler only recognizes `/name/` markers up to three characters long.
</Aside>

## How to use breakpoints

In Elevate, breakpoints are applied using the `/breakpoint/` syntax in your class list. For example: 
```html
<div class="pd:d4 /lg/ pd:d8 /2xl/ pd:d12">Responsive, Organized</div>
```
