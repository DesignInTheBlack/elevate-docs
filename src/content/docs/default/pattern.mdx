`pattern` paints a repeating background. The pattern draws in the element's text color, so `fg-` sets the pattern's color and `bg-` the color behind it.

| Modifier | Values | Compiles to | Example |
|---|---|---|---|
| Pattern | `thinstripes`, `thickstripes`, `zigzag`, `cotton`, `hatching`, `honeycomb`, `microfiber`, `bubbles`, `velvet`, `grid`, `tape`, `shimmer`, `halftone`, `pointgrid`, `herringbone`, `speckled`, `lattice`, `plastic`, `glow`, `curtains`, `changeling`, `headshot`, `wheat`, `carbon`, `finish`, `prism` | `background` | `pattern:carbon` |
| Pattern color | `fg-` plus a [color token](/default/colors/) | `color` | `pattern:carbon:fg-indigo+2` |
| Background color | `bg-` plus a color token | `background-color` | `pattern:carbon:bg-indigo-2` |

```html
<section class="pattern:hatching:fg-grey+3:bg-white">…</section>
```

<Aside type="caution" title="Experimental">
Patterns are built from layered CSS gradients. They render best in Chrome and may look different in other browsers. Since `fg-` sets `color`, text inside a patterned element takes the pattern color too.
</Aside>
