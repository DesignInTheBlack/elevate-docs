---
title: Outline
description: "Focus rings and outlines that don't affect layout."
---

Outlines draw outside the border and don't change layout, which makes them right for focus rings. Combine any of these modifiers on one `outline` class.

| Modifier | Values | Compiles to | Example |
|---|---|---|---|
| Color | Any [color token](/default/colors/) | `outline-color` | `outline:indigo` |
| Width | Any [spacing token](/default/spacing/) | `outline-width` | `outline:d0` |
| Style | `solid`, `dashed`, `dotted`, `double`, `groove`, `ridge`, `inset`, `outset`, `none`, `hidden` | `outline-style` | `outline:solid` |
| Offset | `off-` plus a spacing token | `outline-offset` | `outline:off-d1` |
| Radius | `round-` plus a spacing token | `border-radius` | `outline:round-d2` |

There's no CSS `outline-radius`, so `round-` sets the element's `border-radius`, which outlines follow in current browsers.

```html title="A clear focus ring"
<button class="@focus-visible:[outline:solid:d0:indigo:off-d1]">Save</button>
```
