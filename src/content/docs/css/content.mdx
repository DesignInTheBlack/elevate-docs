---
title: "Align and justify"
description: "Align and distribute content in flex and grid containers."
---

`content` and `items` set alignment on a flex or grid container. The prefix picks the axis: `just-` for the inline axis (`justify-*`), `align-` for the block axis (`align-*`). Use several on one class, for example `content:just-center:align-start`.

For flex rows and columns, [`row` and `col`](/css/flex/) are usually simpler, since they work on screen axes.

## `content`

Positions the content as a whole: tracks in a grid, lines in a wrapping flex container.

| Modifier | Compiles to | Values |
|---|---|---|
| `just-` | `justify-content` | `start`, `end`, `center`, `stretch`, `between`, `around`, `evenly`, `left`, `right` |
| `align-` | `align-content` | `start`, `end`, `center`, `stretch`, `baseline`, `space-between`, `space-around`, `space-evenly` |

The distribution values are spelled differently on each axis: `just-between` but `align-space-between`.

```html title="Center a grid's tracks horizontally, pack them to the top"
<div class="grid:cols-3 content:just-center:align-start">…</div>
```

## `items`

Positions each child within its own area.

| Modifier | Compiles to | Values |
|---|---|---|
| `just-` | `justify-items` | `start`, `end`, `center`, `stretch`, `baseline`, `self-start`, `self-end` |
| `align-` | `align-items` | `start`, `end`, `center`, `stretch`, `baseline`, `self-start`, `self-end` |

```html
<div class="grid:cols-2 items:just-center:align-center">…</div>
```
