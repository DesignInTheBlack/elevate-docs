---
title: "Opacity"
description: "Make an element see-through."
---

`opacity` takes a number from `0` (invisible) to `1` (solid).

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `opacity` | A number, for example `0.2` or `0.65` | `opacity` | `opacity:0.65` |

```html title="Dim a card, and bring it back on hover"
<div class="opacity:0.65 @hover:[opacity:1]">…</div>
```
