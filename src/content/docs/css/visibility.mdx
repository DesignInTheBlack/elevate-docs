---
title: "Visibility"
description: "Hide an element while keeping its space."
---

These are standalone classes. Unlike `hidden`, which removes the element from the layout, `invisible` keeps the space it takes up.

| Class | Compiles to |
|---|---|
| `visible` | `visibility: visible` |
| `invisible` | `visibility: hidden` |
| `collapse` | `visibility: collapse` |

```html
<span class="invisible">Placeholder that still takes up room</span>
```
