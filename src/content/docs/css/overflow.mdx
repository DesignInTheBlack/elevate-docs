---
title: Overflow
description: "Clip, scroll or show content that doesn't fit."
---

Elevate CSS features compound property for specifying the overflow of an element:

### `overflow` property modifiers

| Property   | Expected Values | Example     |
|------------|--------------------|-----------------------|
| `overflow` |  `visible`, `hidden`, `scroll`, `auto`  |  `overflow:hidden`  |

### Axis-specific overflow

| Property   | Expected Values | Example     |
|------------|--------------------|-----------------------|
| `overflow-x` |  `visible`, `hidden`, `scroll`, `auto`  |  `overflow-x:scroll`  |
| `overflow-y` |  `visible`, `hidden`, `scroll`, `auto`  |  `overflow-y:auto`  |
