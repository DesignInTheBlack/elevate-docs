---
title: "Aspect ratios"
description: "Lock an element to a named shape."
---

Give images, videos and cards a fixed shape that holds as the width changes. Use them as `aspect:video`, `aspect:square` and so on.

| Value | Ratio | Value | Ratio |
|---|---|---|---|
| `auto` | auto | `pano` | 2 / 1 |
| `square` | 1 / 1 | `instagram` | 4 / 5 |
| `video` | 16 / 9 | `thumbnail` | 4 / 3 |
| `widescreen` | 21 / 9 | `card` | 7 / 5 |
| `banner` | 3 / 1 | `gallery` | 1.5 / 1 |
| `section` | 4 / 3 | `feature` | 5 / 4 |
| `landscape` | 16 / 10 | `facebook` | 1.91 / 1 |
| `portrait` | 3 / 4 | `wide-banner` | 5 / 1 |

```html title="A responsive video frame"
<div class="aspect:video w:full">…</div>
```
