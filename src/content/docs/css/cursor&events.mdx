title: "Cursor and pointer events"
description: "Set the cursor, and decide whether an element responds to the pointer."
---

## `cursor`

| Values | Compiles to | Example |
|---|---|---|
| `default`, `pointer`, `text`, `crosshair`, `not-allowed`, `progress`, `wait`, `help`, `context-menu`, `move`, `grab`, `grabbing` | `cursor` | `cursor:pointer` |
| `col-resize`, `row-resize`, `n-resize`, `e-resize`, `s-resize`, `w-resize`, `ne-resize`, `nw-resize`, `se-resize`, `sw-resize` | `cursor` | `cursor:col-resize` |

```html title="A draggable card"
<li class="cursor:grab @active:[cursor:grabbing]">…</li>
```

## `events`

`events:none` makes an element ignore the pointer, so clicks pass through to whatever is underneath. The SVG values control which painted parts of a shape respond.

| Values | Compiles to | Example |
|---|---|---|
| `auto`, `none`, `all` | `pointer-events` | `events:none` |
| `visible`, `visible-paint`, `visible-fill`, `visible-stroke`, `fill`, `stroke` | `pointer-events` (`visiblePainted`, `visibleFill`, `visibleStroke`, …) | `events:visible-fill` |

```html title="A decorative overlay that doesn't block clicks"
<div class="absolute inset:d0 events:none">…</div>
```
