Transforms take literal CSS, so their values are pass-through: wrap them in parentheses and use `_` for spaces.

| Property | Compiles to | Example |
|---|---|---|
| `transform` | `transform` | `transform:(translateY(-4px)_scale(1.02))` |
| `origin` | `transform-origin` | `origin:(top_left)` |
| `translate` | `translate` | `translate:(10px_20px)` |
| `scale` | `scale` | `scale:(1.1)` |
| `rotate` | `rotate` | `rotate:(45deg)` |
| `skew` | `transform` | `skew:(skew(10deg))` |

`translate`, `scale` and `rotate` are the individual CSS properties, so they combine with each other and with `transform` instead of replacing it. Separate `translate` values with `_`, not commas. `skew` has no CSS property of its own, so it writes `transform` and needs the full `skew()` function.

```html title="Lift a card on hover"
<article class="transition:snappy @hover:[transform:(translateY(-4px))]">…</article>
```

<Aside title="Pass-through means literally">
The value in parentheses is written into the CSS exactly as you type it, with each `_` turned into a space. Elevate doesn't check it, so a typo there won't fail the build.
</Aside>
