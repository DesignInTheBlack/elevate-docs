---
title: "Vertical alignment"
description: "Line up inline elements and table cells."
---

`vertical` sets `vertical-align`. It affects inline content, like an icon next to text, and table cells. It doesn't move block elements. For those, use [flex alignment](/css/flex/).

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `vertical` | `baseline`, `sub`, `super`, `top`, `text-top`, `middle`, `bottom`, `text-bottom` | `vertical-align` | `vertical:middle` |

```html title="An icon that sits centered on the line"
<p>Saved <svg class="vertical:middle">…</svg></p>
```
