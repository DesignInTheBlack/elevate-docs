## Color and image

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `bg-color` | Any [color token](/default/colors/) | `background-color` | `bg-color:indigo+4` |
| `bg-img` | A pass-through value | `background-image` | `bg-img:(url(hero.jpg))` |
| `bg-exact` | A pass-through size | `background-size` | `bg-exact:(50%_auto)` |

For a [gradient](/default/gradient/) or a [pattern](/default/pattern/), use those properties instead.

## Fitting the background

`bg-attr` takes any mix of these modifiers.

| Modifier | Values | Compiles to |
|---|---|---|
| Size | `cover`, `contain` | `background-size` |
| Position | `center`, `center-top`, `center-bottom`, `left-top`, `left-center`, `left-bottom`, `right-top`, `right-center`, `right-bottom` | `background-position` |
| Repeat | `no-repeat`, `repeat`, `repeat-x`, `repeat-y`, `space`, `round`, `initial`, `revert`, `revert-layer`, `unset` | `background-repeat` |
| Attachment | `scroll`, `fixed`, `local` | `background-attachment` |
| Clip | `border`, `padding`, `content`, `text` | `background-clip` (`border-box`, …, `text`) |
| Origin | `origin-border`, `origin-padding`, `origin-content` | `background-origin` |

```html title="A full-bleed photo"
<section class="bg-img:(url(hero.jpg)) bg-attr:cover:center:no-repeat min-h:c11">…</section>
```

```html title="Gradient text"
<h1 class="gradient:fadetoblack bg-attr:text text:transparent">…</h1>
```
