---
title: "Margin and padding"
description: "Space around and inside elements, on every side or just the ones you name."
---

`mg` sets margin and `pd` sets padding. Both take [spacing tokens](/default/spacing/), plus sizing keywords like `auto` and `0`.

| Values | Applies to | Example |
|---|---|---|
| One | All four sides | `pd:d4` |
| Two | First: left and right. Second: top and bottom | `pd:d6:d3` |
| Four | Top, left, right, bottom, in that order | `mg:d2:d4:d4:d8` |

The four-value order is Elevate's own: top, left, right, bottom. It isn't CSS's clockwise order. Use one, two or four values. With three, the bottom side is left unset.

```html title="A button with more room at the sides"
<button class="pd:d4:d2">Continue</button>
```

## One axis or one side

| Property | Sets | Example |
|---|---|---|
| `pd-x`, `mg-x` | Left and right | `mg-x:auto` |
| `pd-y`, `mg-y` | Top and bottom | `pd-y:c1` |
| `pd-t`, `pd-r`, `pd-b`, `pd-l` | One side of padding | `pd-t:d2` |
| `mg-t`, `mg-r`, `mg-b`, `mg-l` | One side of margin | `mg-b:d6` |

`mg-x:auto` centers a block that has a width, the same as the [`center`](/guides/layout/) layout class.

## Logical sides

For layouts that should flip in right-to-left languages, use the logical properties. Each takes one spacing token.

| Margin | Padding |
|---|---|
| `margin-inline`, `margin-inline-start`, `margin-inline-end` | `padding-inline`, `padding-inline-start`, `padding-inline-end` |
| `margin-block`, `margin-block-start`, `margin-block-end` | `padding-block`, `padding-block-start`, `padding-block-end` |

```html
<li class="padding-inline-start:d4">…</li>
```
