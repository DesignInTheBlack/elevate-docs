title: Borders
description: "Width, style, color and radius, on every side or just one."
---

## `bd`

One class sets any mix of width, style, color and radius on all four sides.

| Modifier | Values | Compiles to | Example |
|---|---|---|---|
| Width | `width-` plus a [spacing token](/default/spacing/) | `border-width` | `bd:width-d0` |
| Style | `solid`, `dashed`, `dotted`, `double`, `groove`, `ridge`, `inset`, `outset`, `none`, `hidden` | `border-style` | `bd:solid` |
| Color | Any [color token](/default/colors/) | `border-color` | `bd:grey+3` |
| Radius | `round-` plus a spacing token | `border-radius` | `bd:round-d3` |
| One corner | `roundtl-`, `roundtr-`, `roundbl-`, `roundbr-` plus a spacing token | `border-top-left-radius`, … | `bd:roundtl-d4` |

```html title="A hairline card"
<div class="bd:width-d0:solid:grey+3:round-d4 pd:d6">…</div>
```

## One side

`bd-t`, `bd-r`, `bd-b` and `bd-l` take width, style and color for that side. Radius belongs to `bd`, since corners are shared by two sides.

| Property | Example |
|---|---|
| `bd-t` | `bd-t:width-d0:solid:grey+3` |
| `bd-r` | `bd-r:width-d0:solid:grey+3` |
| `bd-b` | `bd-b:width-d1:dashed:indigo` |
| `bd-l` | `bd-l:width-d1:solid:indigo` |

## Shorthands and border images

These take literal CSS in parentheses, with `_` for spaces.

| Property | Compiles to | Example |
|---|---|---|
| `border-x` | `border-inline` | `border-x:(1px_solid_currentColor)` |
| `border-y` | `border-block` | `border-y:(1px_solid_currentColor)` |
| `border-image-source` | `border-image-source` | `border-image-source:(url(frame.png))` |
| `border-image-slice` | `border-image-slice` | `border-image-slice:(30)` |
| `border-image-width` | `border-image-width` | `border-image-width:(10px)` |
| `border-image-outset` | `border-image-outset` | `border-image-outset:(5px)` |
| `border-image-repeat` | `border-image-repeat` | `border-image-repeat:(stretch)` |

Table borders, `border-collapse` and `border-spacing`, are on [Lists and tables](/css/lists-and-tables/).
