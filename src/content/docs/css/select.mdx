---
title: "Select"
description: "Control whether people can select text."
---

Use `select:none` on interface chrome like buttons and tabs, and `select:all` when one click should grab the whole value, such as a code or an ID.

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `select` | `none`, `auto`, `text`, `contain`, `all` | `user-select` | `select:none` |

```html
<button class="select:none">Next</button>
<code class="select:all">ELV-2026-0042</code>
```
