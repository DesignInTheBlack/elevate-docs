---
title: "SVG and media"
description: "Color and stroke SVG icons with your tokens."
---

Style inline SVGs with the same tokens as everything else.

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `fill` | Any [color token](/default/colors/) | `fill` | `fill:indigo` |
| `stroke` | Any color token | `stroke` | `stroke:grey-2` |
| `stroke-width` | Any [spacing token](/default/spacing/) | `stroke-width` | `stroke-width:d0` |

```html title="A line icon in your palette"
<svg class="stroke:grey-2 stroke-width:d0 fill:transparent" viewBox="0 0 24 24">…</svg>
```
