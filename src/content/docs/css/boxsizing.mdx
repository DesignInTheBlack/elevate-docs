---
title: "Box sizing"
description: "Decide whether padding and borders count toward an element's size."
---

With `border-box`, a `w:c10` element stays exactly that wide no matter its padding.

| Class or property | Values | Compiles to |
|---|---|---|
| `border-box` | none (standalone) | `box-sizing: border-box` |
| `content-box` | none (standalone) | `box-sizing: content-box` |
| `box-decoration-break` | `slice`, `clone` | `box-decoration-break` |

`box-decoration-break:clone` gives each line of wrapped inline text its own padding and rounded corners.

```html
<span class="box-decoration-break:clone bg-color:yellow+3 pd-x:d1">A highlight that wraps cleanly</span>
```
