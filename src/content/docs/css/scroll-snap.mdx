---
title: "Scroll snap"
description: "Make a scroll area settle on items, like a carousel."
---

Set the snap type on the scroller and the alignment on each item.

| Property | Values | Compiles to | Example |
|---|---|---|---|
| `scroll-snap-type` | `none`, `x`, `y`, `block`, `inline`, `both`, each also with `-mandatory` or `-proximity` | `scroll-snap-type` | `scroll-snap-type:x-mandatory` |
| `scroll-snap-align` | `none`, `start`, `end`, `center` | `scroll-snap-align` | `scroll-snap-align:start` |

`x-mandatory` compiles to `scroll-snap-type: x mandatory`.

```html title="A horizontal carousel"
<ul class="row gap:d4 overflow-x:auto scroll-snap-type:x-mandatory">
  <li class="scroll-snap-align:start">…</li>
</ul>
```
