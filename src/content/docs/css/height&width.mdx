---
title: "Height and width"
description: "Size elements with tokens, percentages and content keywords."
---

Every sizing property takes a [spacing token](/default/spacing/) or one of the keywords below.

| Property | Compiles to | Example |
|---|---|---|
| `w` | `width` | `w:c10` |
| `h` | `height` | `h:d12` |
| `min-w` | `min-width` | `min-w:c4` |
| `max-w` | `max-width` | `max-w:s4` |
| `min-h` | `min-height` | `min-h:hScreen` |
| `max-h` | `max-height` | `max-h:c11` |

## Keywords

| Value | Compiles to |
|---|---|
| `0` | `0` |
| `full` | `100%` |
| `wScreen` | `100vw` |
| `hScreen` | `100vh` |
| `auto` | `auto` |
| `min-content` | `min-content` |
| `max-content` | `max-content` |
| `fit-content` | `fit-content` |

These keywords live in the spacing token set, so they work anywhere a spacing token does, for example `mg-x:auto` or `gap:0`.

```html title="A full-height hero, and a readable column inside it"
<section class="min-h:hScreen col:x-center:y-center">
  <div class="w:full max-w:s4">…</div>
</section>
```
