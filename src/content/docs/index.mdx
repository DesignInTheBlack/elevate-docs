<div class="home">

<section class="home-section">
<h2>Write what you mean.</h2>
<p class="home-sub">Every class names a token from your design system. Elevate looks up the value and writes exactly that CSS. Change the token, and every class that uses it follows.</p>
<TokenMap />
</section>

<section class="home-section">
<h2>A whole layout, in one class.</h2>
<p class="home-sub">Direction, alignment and wrapping live in a single class, on axes you can see: <code>x</code> is always horizontal, <code>y</code> is always vertical. Try it.</p>
<FlexLab />
</section>

<section class="home-section">
<h2>Everything else stays in your HTML.</h2>
<p class="home-sub">The things that usually send you back to a stylesheet have a place in the class list.</p>

<div class="home-features">
<div>
<h3>Envelopes</h3>
<p>Name a list of classes once with <code>env:card</code>, reuse it anywhere, and reopen it with <code>env:card:open</code> when you need to edit.</p>
<a href="/guides/4-env-aliases/">How envelopes work</a>
</div>
<div>
<h3>Context scopes</h3>
<p>Draw a boundary with <code>ctx:card</code> and end it with <code>ctx:end:card</code>. Styles inside it can't leak into the rest of the page.</p>
<a href="/guides/3-specificity/">Scoping and specificity</a>
</div>
<div>
<h3>Relational selectors</h3>
<p>Style children, descendants, siblings or the parent from inside a scope with <code>@child</code>, <code>@descendants</code>, <code>@siblings</code> and <code>@ancestor</code>.</p>
<a href="/reference/supported-selectors/">Supported selectors</a>
</div>
<div>
<h3>Grouped states</h3>
<p>Change several things on one state, together: <code>@hover:[bg-color:indigo_text:white]</code>.</p>
<a href="/reference/supported-selectors/">States and pseudo-elements</a>
</div>
</div>
</section>

<section class="home-section home-close">
<h2>Ship only what you use.</h2>
<p class="home-sub">Nothing is prebuilt. Elevate watches your files and compiles CSS for the classes you actually write, mobile-first, with errors that point to the exact file and line.</p>

```bash title="Start in three commands"
npm install elevate-framework
npx elevate-framework prepare
npm run elevate
```
